# Contributing

Contributions must preserve privacy minimization and draft-only behavior.

1. Use fictional `.invalid` addresses and identifiers in fixtures.
2. Add tests for redaction failures and unsafe boundary changes.
3. Run `python -m unittest discover -s tests -v`.
4. Document any new stored field or external boundary.
5. Do not add auto-send or auto-approval paths without a separate design review.

Security reports belong in a private advisory.
